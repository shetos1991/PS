# SHETOS PRO - GitHub Pages

1. Extract ZIP. Upload **all files and folders inside** to the root of the PS repository, rather than the ZIP file itself.
2. Commit changes to `main`.
3. Settings → Pages → Source: **GitHub Actions**.
4. Check Actions for a successful deployment.
5. Open https://shetos1991.github.io/PS/ .

The site's original controller logic remains unchanged. Test live features with a compatible wired controller on Chrome/Edge before using any calibration or permanent save operation. Save a backup or create a branch before replacing an existing version.
